Privacidad

Torrujuegos es un proyecto personal y gratuito, sin anuncios ni compras. Esta página explica qué datos guarda el juego y para qué.

Responsable: David Gómez Picazo · Contacto: [tu email]

Qué datos se guardan

  • Nombre o apodo de cada niño, mes y año de nacimiento y el color elegido.
  • Progreso en los juegos: estrellas, pegatinas, niveles, aciertos y fallos por habilidad, misiones hechas.
  • Minutos jugados cada día, para el límite de tiempo.

No se piden emails, teléfonos, fotos, ubicación ni ningún otro dato. Se recomienda usar un apodo.

Para qué

Solo para que el juego funcione: adaptar la dificultad a la edad, guardar el progreso, aplicar el límite diario y mostrar a los padres qué habilidades les cuestan más. No se usan para publicidad, no se ceden a nadie y no se analizan con otros fines.

Dónde se guardan

Siempre en el propio dispositivo. Si la familia crea un código de familia, además se guardan en un servidor de Supabase para poder jugar en varios dispositivos. Cada familia solo puede acceder a sus datos con su código; en el servidor no se guarda el código, sino una huella cifrada de él.

La base legal es el consentimiento del padre, madre o tutor, que se pide al crear la familia.

Cuánto tiempo

Mientras la familia use el juego. El historial de minutos se borra solo a los 60 días.

Cómo borrar los datos

En Padres → Familia → Borrar datos de internet se eliminan para siempre del servidor. En Padres → Niños se puede eliminar a cada niño. Borrar los datos del navegador elimina la copia del dispositivo. También puedes escribir al contacto de arriba para ejercer tus derechos de acceso, rectificación o supresión.
